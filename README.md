## Sobre o projeto

O BlockEduCode é uma plataforma educacional desenvolvida com o
objetivo de auxiliar no ensino de lógica de programação e algoritmos.

A plataforma permite que estudantes desenvolvam algoritmos em Portugol
utilizando uma interface visual baseada em blocos de código, reduzindo
a barreira inicial encontrada por alunos que estão começando a aprender
programação.

O projeto foi desenvolvido integralmente por mim, desde a arquitetura
do backend até o desenvolvimento do frontend e do interpretador da
linguagem.

---

## Funcionalidades

- Programação visual através de blocos
- Editor de código Portugol
- Interpretador Portugol
- Execução de algoritmos em tempo real
- Console interativo de entrada e saída
- Validação de código
- Sistema de autenticação
- Controle de acesso por perfil
- Ambientes para professores e alunos
- Gerenciamento de turmas
- Atividades de programação
- Dashboard de desempenho
- Acompanhamento de alunos
- Presença online

Services
↓

PostgreSQL
